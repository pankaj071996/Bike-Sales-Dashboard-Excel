# Bike Sales Dashboard (Microsoft Excel)

## Project Overview

This project is an interactive Bike Sales Dashboard developed in Microsoft Excel to analyze customer purchasing behavior. The dashboard enables users to explore sales patterns through dynamic filters and visualizations.

---

## Dashboard Preview

![Bike Sales Dashboard](Dashboard%20Screenshot.png)
---

## Objectives

- Analyze bike purchase trends.
- Compare average customer income.
- Study customer age groups.
- Analyze commute distance.
- Filter data dynamically using slicers.

---

## Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization
- Dashboard Design

---

## Dashboard Features

- Average Income per Purchase
- Customer Age Brackets
- Customer Commute Analysis
- Interactive Filters
  - Marital Status
  - Region
  - Education
  - Gender

---

## Key Insights

- Male customers have a higher average income than female customers.
- Middle-aged customers purchase bikes more frequently.
- Customers with shorter commute distances show higher purchase rates.
- Interactive slicers allow dynamic data exploration.
